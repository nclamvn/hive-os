no stationary point. Otherwise all solutions form p=p0+Nq, HN=0, and Q is

## Exact dual certificates, not simplex verdicts

Let z_i=p_i+R>=0, epsilon>=0, with valid additional bounds z_i<=2R and
epsilon<=1. Convert every affine closed row c+a.p>=0 into a standard
inequality A_r.(z,epsilon)<=b_r. A strict row uses c+a.p>=epsilon.
Stationary equalities are paired closed inequalities. All strict rows share
the SAME epsilon: for a finite row inventory, a point satisfies them strictly
iff some epsilon>0 is feasible (cap1 is harmless).

An exact multiplier lambda>=0 with lambda A>=e_epsilon coefficientwise and
lambda b<=0 proves epsilon<=lambda A.z<=lambda b<=0 at any feasible
nonnegative z. Alternatively lambda A>=0 and lambda b<0 proves even the
relaxed system infeasible. The checker must independently reconstruct EVERY
row, bounds and objective, then verify the multiplier inequalities exactly.
Neither solver optimal/infeasible text nor a supplied row matrix is evidence.

These dual checks cover all singular families because the feasibility system
uses the original five bounded offsets and all stationary equalities, not
only a sampled nullspace point or a single constant row. If a dual cannot be
produced, the leaf remains unresolved; no fallback acceptance is permitted.
