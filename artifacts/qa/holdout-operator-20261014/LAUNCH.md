# Launch checklist

**PARKED / NOT RUN as of 2026-10-14.** This historical checklist is not the
default next task. Read [PROTOCOL_ERRATA.md](PROTOCOL_ERRATA.md) and
[PRD Phase 2](../../../docs/product/PRD_PHASE_2.md) before any separately selected
operator work. Sources, participants and assessment need review then.

This checklist is deliberately short. Do not change the product or source pack
after the first participant starts.

1. Assign an anonymous operator code and one of the counterbalanced pairings in
   `PROTOCOL.md`. Give the participant only the applicable operator brief and
   source PDFs/text. Do not give the rubric.
2. Record a UTC start and start a visible stopwatch. The participant gets the
   original release for checkpoint 1, then only the stated checkpoint-2 update.
3. For the generic arm, retain final text and source locators. For the HIVE arm,
   retain the final saved URL/revision, citation list and export result. Do not
   repair a failure while timing.
4. Complete a row in `RUN_SHEET.md`; copy outputs into an assessor packet with
   arms anonymized as X/Y.
5. Have the assessor score `ASSESSOR_RUBRIC.md` without the X/Y mapping. Only
   then unblind, calculate median active seconds and report the result exactly
   under the decision rule.

Two operators/four case runs support a small usability pilot only; they do not
establish population-level effects or ROI. A single run is a rehearsal.
