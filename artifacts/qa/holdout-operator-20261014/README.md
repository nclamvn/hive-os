# Operator pilot proposal — status: PARKED, NOT RUN

Owner-approved Phase 2 direction, 2026-10-14, supersedes default launch of this
proposal. See [PRD Phase 2](../../../docs/product/PRD_PHASE_2.md) and the
[methodology correction](PROTOCOL_ERRATA.md). Original draft protocol/rubric are
retained for history; their READY/frozen labels are not current execution status.
No participants, label-blind grading, model outputs or timed human runs exist.

This is a small, pre-registered field pilot of HIVE as a controlled authoring
surface, not a benchmark of model intelligence. It was created after the one-case
LACAHSA comparison found no content-quality advantage for HIVE and did find
revision/preimage controls. Its purpose is to test whether those controls matter
to an actual operator on a multi-document update and handover task.

The two fresh public cases are separate from the LACAHSA calibration:

| Case | Lifecycle | Pack |
| --- | --- | --- |
| SFC-ERP-2025-0370 | RFP -> Addenda 1–3 -> Addendum 4 resubmission/timeline | 5 official PDFs |
| SFC-JMS-2026-0023 | RFP -> Addendum 1 -> award notification/handover | 3 official PDFs |

The study materials were prepared before any participant output:

- `PROTOCOL.md` — design, parity and stop rules.
- `ASSESSOR_RUBRIC.md` — 10 pre-locked checks per case; keep away from operators.
- `OPERATOR_BRIEF_A.md` and `OPERATOR_BRIEF_B.md` — standard operating briefs.
- `SOURCE_MANIFEST.md` — origin, scope and SHA-256 of each source.
- `RUN_SHEET.md` — blank receipts for time, omissions and traceability.

No model output, result, score, or advantage claim exists yet. Do not treat source
availability or a polished demo as a completed measurement.

## Honest claim boundary

If separately selected for a real user need, this proposal can support exploratory
usability observations. Two operators/four operator-case runs cannot establish a
general superiority/ROI claim. Public source selection does not establish that
models have never seen the cases; the author of the rubric has already read the
sources. No independent domain expert has validated the key. Grading with arm
labels hidden is a different claim from unseen tasks or independent expertise.

Original source PDFs remain local with their hashes/origins committed. Generated
text extractions and cover previews were removed as reproducible derivatives of
an unrun proposal. Raw candidate PDFs are excluded from Git (including incidental
conference attendee details); future work must minimize inputs before sharing.
