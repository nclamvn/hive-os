# Methodology correction and Phase 2 routing — 2026-10-14

This note preserves rather than silently rewrites the original unexecuted
`PROTOCOL.md` and `ASSESSOR_RUBRIC.md`. No outputs or results were produced.

## Claims to correct before any possible future use

1. **New-to-project is not unseen-to-model.** These are public RFPs. Their
   training/evaluation exposure is unknown. Calling them a model-blind holdout is
   unsupported. The coordinator has read both sources and the draft answer key.
2. **Rubric is not expert-independent.** It was drafted by the same AI coordinator
   selecting sources; it has not been checked by an outside procurement expert.
   Hidden arm labels may reduce one bias, but do not add domain independence.
3. **Small sample, not general ROI.** Two operators/four case runs are an
   exploratory counterbalanced usability pilot. The proposed 30% threshold is a
   management hypothesis, not an observed effect or statistical power calculation.
   The original pairing table is unclear about run order and must be specified
   before any actual session; participants must not see the answer key.
4. **Bounded documents, not full compliance.** The eight PDFs are candidates for
   a narrow timeline/update exercise. External referenced workbooks, Exhibit A,
   process maps and corrected forms are not all retained here. A full
   proposal-compliance exercise cannot use this as a complete source dossier.
5. **Outcome definitions need refinement.** The original text conflates every
   rubric failure with a critical error. A material missing obligation, minor
   omission, fabricated fact and missing citation require distinct severity and
   source justification; ordinary missing text is not automatically critical.
6. **Tool/time parity needs actual receipts.** Source access and ordinary model
   tools must be comparable. B must not be deprived of generic tools that A has,
   and A must not be deprived of history/self-review. Copying, formatting,
   warning triage, failed actions and export are part of operational burden.

## Routing decision

Owner-approved [PRD Phase 2](../../../docs/product/PRD_PHASE_2.md) parks this
proposal. Do not recruit, create runs or continue collecting sources merely to
obtain an HIVE win. Start from a real user job and the strongest existing
agent/skill alternative. Reconsider this particular pilot only if it answers
that job's unresolved question. Current results, human seconds and ROI: NONE.

Original PDFs are retained locally, byte hashes unchanged. Reproducible text
extractions and cover previews were removed; candidate PDFs stay outside Git.
This reduces repository weight and avoids publishing incidental attendee data.
`SOURCE_SHA256SUMS.txt` is the preserved local acquisition receipt, not a promise
that every reader of the repository has the source bytes available offline.
