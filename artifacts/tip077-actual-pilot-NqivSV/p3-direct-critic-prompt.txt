## Answer

For every allowed initial segment, one of the two parity subsequences is eventually periodic.

## Proof

Write
\[
C_t(x)=\#\{j\le t:a_j=x\}.
\]
Thus the recurrence is \(a_{t+1}=C_t(a_t)\) for \(t\ge N\).

### 1. Only finitely many values can occur infinitely often

Let
\[
K=\max(a_1,\ldots,a_N).
\]
We first prove that every value greater than \(K\) occurs at most \(K\) times.

Suppose otherwise, and let \(t\) be the first index at which some value \(x>K\) has occurred \(K+1\) times. Let its occurrence positions up to \(t\) be
\[
t_1<\cdots<t_{K+1}=t.
\]
All these positions exceed \(N\). Put \(y_i=a_{t_i-1}\). The recurrence gives
\[
C_{t_i-1}(y_i)=x>K.
\]
By the minimality of \(t\), this forces \(y_i\le K\): otherwise an outside value already had more than \(K\) occurrences before \(t\).

Moreover, the \(y_i\) are distinct. Indeed, the counts at successive occurrences of any fixed value strictly increase, so that value cannot generate the same following value \(x\) twice. We have obtained \(K+1\) distinct elements of \(\{1,\ldots,K\}\), a contradiction.

Let \(S\) be the set of values occurring infinitely often. Thus \(S\subseteq\{1,\ldots,K\}\).

The sequence is unbounded. Otherwise some value in its finite range would occur infinitely often, and its increasing occurrence counts would appear as following terms, contradicting boundedness. Consequently infinitely many values first appear after index \(N\). Each such first appearance is followed by \(1\), so \(1\in S\). In particular, \(S\ne\varnothing\).

Put \(r=|S|\). Choose an integer \(L\ge\max(K,N)\) which also bounds the total multiplicity of each finitely occurring value in \(\{1,\ldots,K\}\). By the bound just proved, every value outside \(S\) has total multiplicity at most \(L\).

For any \(x>L\), every occurrence of \(x\) must therefore be generated by a preceding value in \(S\). Each \(s\in S\) generates \(x\) exactly once: its \(x\)-th occurrence exists, occurs after index \(N\), and is followed by \(x\). Hence every \(x>L\) occurs exactly \(r\) times.

Its successive occurrences are followed by \(1,2,\ldots,r\). Since there are infinitely many such \(x\), every value in \(\{1,\ldots,r\}\) occurs infinitely often. Comparing cardinalities gives
\[
S=\{1,\ldots,r\}.
\]

Once the counts of all values in \(S\) exceed \(L\), an occurrence in \(S\) is followed by a value greater than \(L\). Every value greater than \(L\), in turn, is followed by a value in \(\{1,\ldots,r\}=S\). Starting at a sufficiently late occurrence in \(S\), the tail therefore alternates between values in \(S\) and values greater than \(L\).

### 2. The small values follow a counter process

Denote the small terms of this alternating tail by
\[
b_1,b_2,\ldots\in\{1,\ldots,r\}.
\]
Let \(c_i(m)\) be the number of occurrences of \(i\) strictly before the position of \(b_m\). Between \(b_m\) and \(b_{m+1}\) there is exactly one large term, so
\[
c_i(m+1)=c_i(m)+\mathbf1_{i=b_m}.
\]
That large term is
\[
u=c_{b_m}(m)+1=c_{b_m}(m+1)>L.
\]

As established above, a value \(u>L\) is generated exactly once by each \(i\in S\), at the \(u\)-th occurrence of \(i\). By the time the displayed large term has appeared, this generation has happened precisely for those \(i\) satisfying \(c_i(m+1)\ge u\). Therefore
\[
b_{m+1}
=\#\{i:c_i(m+1)\ge c_{b_m}(m+1)\}. \tag{1}
\]
Every \(c_i(m)\) tends to infinity, because every \(i\in S\) occurs infinitely often.

We now prove that any counter process with these properties has an eventually periodic sequence of selected indices.

### 3. Counter lemma

Suppose integer counters \(c_1,\ldots,c_r\) evolve by increasing the selected counter \(c_b\) by \(1\), then selecting
\[
q=\#\{i:c_i\ge c_b\},
\]
where the comparison uses the updated counters. Suppose every counter tends to infinity. Then the selected-index sequence is eventually periodic.

For \(r=1\), this is immediate. Assume \(r\ge2\).

At each state, let
\[
d_1\ge d_2\ge\cdots\ge d_r
\]
be the counters sorted in decreasing order, and define
\[
e_i=c_i-d_i+\mathbf1_{i=b}.
\]
We claim that every \(e_i\) is invariant.

Indeed, suppose the selected counter increases from \(t\) to \(t+1\), and the next selected index is \(q\). Before the update, exactly \(q-1\) counters exceed \(t\); after it, exactly \(q\) counters are at least \(t+1\). Thus the sorted vector changes only by increasing \(d_q\) by \(1\). Consequently
\[
e_i'
=(c_i+\mathbf1_{i=b})-(d_i+\mathbf1_{i=q})
+\mathbf1_{i=q}
=e_i.
\]
This proves the claim.

Let
\[
E=1+\max_i|e_i|.
\]
At every state,
\[
|c_i-d_i|\le E. \tag{2}
\]

Consider a sorted gap \(d_k-d_{k+1}>2E\), where \(1\le k<r\). From (2), for \(i\le k<j\),
\[
c_i\ge d_k-E>d_{k+1}+E\ge c_j.
\]
Hence the counters with labels \(1,\ldots,k\) are strictly larger than all the other counters.

The selected index cannot belong to \(\{1,\ldots,k\}\) in this state. If it did, increasing its counter would preserve this strict separation, and its new rank \(q\) would again lie in \(\{1,\ldots,k\}\). Inductively, only these first \(k\) counters would ever increase thereafter. The remaining counters would stay constant, contradicting the hypothesis that all counters tend to infinity.

Thus, whenever \(d_k-d_{k+1}>2E\), the updated counter belongs to the lower group. Its increase cannot raise this gap: the upper group is unchanged, while the maximum of the lower group cannot decrease.

If instead \(d_k-d_{k+1}\le2E\), the gap after one update is at most \(2E+1\), since the sorted vector changes by increasing exactly one coordinate by \(1\).

It follows that all sorted gaps remain bounded. More explicitly, if
\[
B=\max\left(2E+1,\ \max_{1\le k<r}
\bigl(d_k(1)-d_{k+1}(1)\bigr)\right),
\]
then every gap is at most \(B\) at every later state. Therefore
\[
\max_i c_i-\min_i c_i=d_1-d_r\le(r-1)B. \tag{3}
\]

Normalize each state by subtracting its minimum counter:
\[
\widehat c_i=c_i-\min_j c_j.
\]
By (3), the state
\[
(\widehat c_1,\ldots,\widehat c_r,b)
\]
belongs to a finite set. Its transition is deterministic: adding a common constant to all counters changes neither the ranks nor the normalized next state. A deterministic trajectory in a finite set eventually repeats a state, and from that repetition onward it is periodic. Its selected-index sequence is therefore eventually periodic. This proves the lemma.

### 4. Applying the lemma

The counters from Section 2 satisfy the lemma’s update rule by (1), and every counter tends to infinity. Thus \(b_1,b_2,\ldots\) is eventually periodic.

These are exactly the terms at every other position of a sufficiently late tail of the original sequence. Their positions have one fixed parity. Hence either
\[
(a_{2j-1})_{j\ge1}
\quad\text{or}\quad
(a_{2j})_{j\ge1}
\]
is eventually periodic, as required.

## Scope and gaps

The proof covers every positive integer \(N\) and every positive-integer initial segment. It is structural and uses no finite computation to establish the theorem. No essential gap remains.
