## Answer

At least one of the two parity subsequences is eventually periodic. This holds for every allowed initial segment.

## Proof

Write
\[
C_t(x)=\#\{i\le t:a_i=x\},\qquad
H_t(k)=\#\{x\ge1:C_t(x)\ge k\},
\]
and put \(C_0(x)=H_0(k)=0\). Thus \(H_t(k)\) counts how many distinct values have appeared at least \(k\) times.

The proof first identifies the values that occur infinitely often, then reduces their successive occurrences to a finite-state process.

### 1. A counting identity

For every \(n\ge N\) and \(k\ge1\),
\[
C_n(k)=C_N(k)+H_{n-1}(k)-H_{N-1}(k).
\tag{1}
\]

Indeed, each occurrence of \(k\) at an index \(i+1>N\) corresponds, by the given recurrence, to the \(k\)-th occurrence of the value \(a_i\). The number of such \(k\)-th occurrences at indices \(N,\ldots,n-1\) is exactly
\[
H_{n-1}(k)-H_{N-1}(k).
\]
This proves (1), including the case \(n=N\).

Choose
\[
K=\max\{N,a_1,\ldots,a_N\}.
\]
For \(k>K\), both \(C_N(k)\) and \(H_{N-1}(k)\) vanish. Consequently,
\[
C_n(k)=H_{n-1}(k)\qquad(n\ge N,\ k>K).
\tag{2}
\]
In particular, for each fixed \(n\ge N\), the counts \(C_n(k)\) are nonincreasing as \(k\) ranges over \(K+1,K+2,\ldots\).

We claim that
\[
C_n(k)<k\qquad(n\ge N,\ k>K).
\tag{3}
\]
Otherwise, fix \(k>K\) and take the first \(n\) for which \(C_n(k)=k\). Since \(C_N(k)=0\), we have \(n>N\), \(a_n=k\), and \(C_{n-1}(k)=k-1\). The monotonicity just established gives
\[
C_{n-1}(x)\le k-1\qquad(x\ge k).
\]
Thus only the \(k-1\) values \(x<k\) could have appeared at least \(k\) times, so
\[
H_{n-1}(k)\le k-1.
\]
This contradicts (2), which gives \(H_{n-1}(k)=C_n(k)=k\).

Applying (3) to \(K+1\), and then using monotonicity, yields
\[
C_n(k)\le K\qquad(n\ge N,\ k>K).
\tag{4}
\]

### 2. The values occurring infinitely often form an initial interval

Let \(R\) be the set of values occurring infinitely often. By (4),
\[
R\subseteq\{1,\ldots,K\}.
\tag{5}
\]

Also, \(R\) is nonempty. If only finitely many distinct values occur, one occurs infinitely often. If infinitely many distinct values occur, infinitely many have their first occurrence after index \(N\); each such first occurrence is followed by \(1\), so \(1\) occurs infinitely often.

Put \(r=|R|\), so \(1\le r\le K\). For a value outside \(R\), let \(C_\infty(x)\) denote its finite total number of occurrences. Choose an integer \(L\ge K\) large enough that
\[
C_\infty(x)\le L\qquad(x\notin R).
\tag{6}
\]
Such a choice is possible: (4) already bounds all values \(x>K\) by \(K\), leaving only finitely many values to consider.

For \(k>L\), equations (2) and (6) give
\[
C_n(k)
=H_{n-1}(k)
=\#\{x\in R:C_{n-1}(x)\ge k\}.
\tag{7}
\]
Every count belonging to a value in \(R\) tends to infinity. Hence, for each fixed \(k>L\), the right-hand side eventually equals \(r\). Therefore
\[
C_\infty(k)=r\qquad(k>L).
\tag{8}
\]

Now fix \(j\in\{1,\ldots,r\}\). Each value \(k>L\) has a \(j\)-th occurrence, and that occurrence is followed by \(j\). These occurrences lie after \(N\), because \(k>L\ge K\) does not appear in the initial segment. As there are infinitely many choices of \(k\), the value \(j\) occurs infinitely often. Thus
\[
\{1,\ldots,r\}\subseteq R.
\]
Both sets have cardinality \(r\), so
\[
R=\{1,\ldots,r\}.
\tag{9}
\]

### 3. Eventual alternation and the counter recurrence

Choose \(T\ge N+1\) such that:

- none of the values \(r+1,\ldots,L\) occurs at or after \(T\);
- \(C_t(i)>L\) for every \(i\in\{1,\ldots,r\}\) and every \(t\ge T\).

This is possible by (9).

For \(t\ge T\), if \(a_t\le r\), then
\[
a_{t+1}=C_t(a_t)>L.
\]
If \(a_t>L\), then (7) gives
\[
1\le a_{t+1}=C_t(a_t)\le r.
\]
Thus the sequence eventually alternates between values in \(\{1,\ldots,r\}\) and values greater than \(L\).

Choose \(t_0\ge T\) with \(a_{t_0}\le r\), and define
\[
b_m=a_{t_0+2m},\qquad h_m=a_{t_0+2m+1}
\qquad(m\ge0).
\]
Here \(b_m\in\{1,\ldots,r\}\) and \(h_m>L\).

For \(1\le i\le r\), let
\[
c_i(m)=C_{t_0+2m-1}(i).
\]
These are the counts immediately before \(b_m\) occurs. Consequently,
\[
c_i(m+1)=c_i(m)+\mathbf1_{\{i=b_m\}},
\qquad
h_m=c_{b_m}(m)+1=c_{b_m}(m+1).
\tag{10}
\]
Using (7) at the occurrence of \(h_m\), we obtain
\[
b_{m+1}
=\#\{i\in\{1,\ldots,r\}:c_i(m+1)\ge c_{b_m}(m+1)\}.
\tag{11}
\]
Furthermore, every \(c_i(m)\) tends to infinity, because every value \(1,\ldots,r\) occurs infinitely often.

We now prove the counter lemma needed for (10)–(11).

### 4. Counter lemma

**Lemma.** Suppose a process has integer counters \(c_1,\ldots,c_r\) and an index \(b\in\{1,\ldots,r\}\). Each step increments counter \(b\) by one, then sets the next index to
\[
b'=\#\{i:c'_i\ge c'_b\},
\]
where \(c'\) is the updated counter vector. If every counter tends to infinity, then the index sequence is eventually periodic.

**Proof.** Let
\[
s_1\ge s_2\ge\cdots\ge s_r
\]
be the counter values sorted in decreasing order, with repetitions retained. Write \(e_i\) for the \(i\)-th unit vector.

Under one update,
\[
c'=c+e_b,\qquad s'=s+e_{b'}.
\tag{12}
\]
To verify the second equality, write \(v=c_b\), and let \(q\) be the number of counters whose old values are at least \(v+1\). Since the counters are integers, incrementing the chosen counter from \(v\) to \(v+1\) changes only the \((q+1)\)-st sorted entry, increasing it by one. The updated number of counters at least \(v+1\) is \(q+1=b'\). This also handles all ties.

It follows from (12) that
\[
u=c-s+e_b
\tag{13}
\]
is invariant:
\[
c'-s'+e_{b'}=c-s+e_b.
\]
Set
\[
D=1+\max_i|u_i|.
\]
At every stage,
\[
|c_i-s_i|\le D.
\tag{14}
\]

For \(1\le k<r\), consider the sorted gap
\[
g_k=s_k-s_{k+1}.
\]
Suppose \(g_k>2D\). By (14), every counter labelled \(1,\ldots,k\) is strictly larger than every counter labelled \(k+1,\ldots,r\). Indeed,
\[
c_i\ge s_k-D>s_{k+1}+D\ge c_j
\qquad(i\le k<j).
\tag{15}
\]

At such a stage, the current index cannot satisfy \(b\le k\). If it did, incrementing that counter would make the next index at most \(k\). The strict separation in (15) would persist, and induction would show that all subsequent updates occur among counters \(1,\ldots,k\). The remaining counters would stay constant, contradicting their assumed divergence.

Hence \(b>k\) whenever \(g_k>2D\). The chosen counter then lies below the largest \(k\) counters. Incrementing it by one cannot increase \(s_k\), because its old value is at most \(s_{k+1}<s_k\). It cannot decrease \(s_{k+1}\). Therefore
\[
g'_k\le g_k\qquad\text{whenever }g_k>2D.
\tag{16}
\]
For any step, (12) also gives \(g'_k\le g_k+1\). Together these observations imply
\[
g_k(m)\le G_k:=\max\{g_k(0),\,2D+1\}
\qquad(m\ge0).
\tag{17}
\]

Thus the difference between the largest and smallest counters is bounded:
\[
\max_i c_i(m)-\min_i c_i(m)
=s_1(m)-s_r(m)
\le B:=\sum_{k=1}^{r-1}G_k.
\tag{18}
\]
For \(r=1\), the sum is empty and \(B=0\).

Normalize the counters by subtracting their minimum:
\[
d_i(m)=c_i(m)-\min_j c_j(m).
\]
Every \(d_i(m)\) is an integer between \(0\) and \(B\). Hence there are only finitely many possible states
\[
\bigl(b_m,d_1(m),\ldots,d_r(m)\bigr).
\]

The next normalized state is determined entirely by the current one: increment \(d_{b_m}\), compute the next index by the rank rule, and subtract the new minimum. Adding a common constant to all counters changes none of these operations.

A state must therefore repeat. Determinism then makes the subsequent states repeat periodically, so the index sequence is eventually periodic. This proves the lemma. \(\square\)

### 5. Conclusion

The counters in (10)–(11) satisfy the lemma, and all tend to infinity. Therefore \((b_m)\) is eventually periodic.

Since
\[
b_m=a_{t_0+2m},
\]
this is a tail of the odd-indexed subsequence when \(t_0\) is odd, and a tail of the even-indexed subsequence when \(t_0\) is even. The corresponding parity subsequence is eventually periodic, as required. \(\square\)

## Scope and gaps

The proof covers every positive integer \(N\) and every positive initial segment. All blocking lemmas are proved above; no essential gap remains. The finite-state conclusion follows from a uniform mathematical bound, not from finite simulation.

## Proof (independent audit)

**1. The counting identity has the correct indexing.**

For each \(i\in\{N,\ldots,n-1\}\), the recurrence gives
\[
a_{i+1}=C_i(a_i).
\]
Thus \(a_{i+1}=k\) exactly when position \(i\) is the \(k\)-th occurrence of its value. Each distinct value contributes exactly once to \(H_t(k)\), at its \(k\)-th occurrence. Consequently,
\[
C_n(k)-C_N(k)=H_{n-1}(k)-H_{N-1}(k).
\]
This also holds at \(n=N\), when both differences vanish. There is no off-by-one error.

For \(k>K\), the initial segment contains no \(k\), and \(N-1<k\), so both initial terms vanish. Hence (2), and the resulting monotonicity in \(k>K\), are justified.

**2. The bound on occurrences of large values is valid.**

If \(C_n(k)\) first reaches \(k\), then \(n>N\), \(a_n=k\), and \(C_{n-1}(k)=k-1\). Since \(n-1\ge N\), the previously established monotonicity applies and gives
\[
C_{n-1}(x)\le k-1\qquad(x\ge k).
\]
Only the \(k-1\) positive values below \(k\) can therefore have count at least \(k\). This contradicts
\[
H_{n-1}(k)=C_n(k)=k.
\]
The first-reaching argument is legitimate because occurrence counts increase by at most one per position. Applying it to \(K+1\) and then using monotonicity proves (4).

**3. The identification \(R=\{1,\ldots,r\}\) is noncircular.**

The argument establishing \(R\ne\varnothing\) covers both possibilities for the number of distinct values. In the infinite-distinct-values case, infinitely many first occurrences lie after \(N\), and each has a distinct successor position containing \(1\).

A uniform \(L\) for values outside \(R\) exists because values above \(K\) already have uniformly bounded counts, while there are only finitely many values at most \(K\).

For any fixed \(k>L\), outsiders cannot contribute to \(H_{n-1}(k)\). All \(r\) members of \(R\) eventually do contribute, so
\[
C_\infty(k)=r.
\]
Thus every \(k>L\) has a \(j\)-th occurrence for each \(1\le j\le r\). Its successor is \(j\), and these successor positions are distinct as \(k\) varies. This proves that every such \(j\) occurs infinitely often. Cardinality then gives the claimed description of \(R\).

**4. Eventual alternation and the counter recurrence are correctly derived.**

After the finitely occurring values \(r+1,\ldots,L\) disappear:

- A value at most \(r\) has current count greater than \(L\), so its successor exceeds \(L\).
- A value greater than \(L\) has current count at most \(r\), by (7), and at least \(1\), because it occurs at the current position.

Hence the eventual alternation is valid.

For the counter indexing, \(c_i(m+1)\) counts through the intervening high-value position. That position contributes nothing to any counter \(i\le r\). Therefore
\[
c_i(m+1)=c_i(m)+\mathbf1_{\{i=b_m\}}.
\]
Applying (7) at the position containing \(h_m\) uses the counts immediately after \(b_m\), which are precisely \(c_i(m+1)\). This proves (11). Every counter diverges because its labelled value belongs to \(R\).

**5. The sorted-counter invariant handles ties correctly.**

If the selected counter has old value \(v\), let
\[
q=\#\{i:c_i\ge v+1\}.
\]
Since the counters are integers, the old sorted entry \(s_{q+1}\) equals \(v\). Raising the selected counter to \(v+1\) changes only that sorted entry, and the new rank count is \(b'=q+1\). Thus
\[
s'=s+e_{b'}.
\]
This remains true when several counters equal \(v\) or \(v+1\); sorting concerns their numerical values, so no tie-breaking convention is needed.

It follows exactly that
\[
c'-s'+e_{b'}=c-s+e_b.
\]
Consequently, the claimed uniform bound \(|c_i-s_i|\le D\) follows from the invariant.

**6. The large-gap implication is valid, with one detail worth making explicit.**

When \(s_k-s_{k+1}>2D\), all counters labelled \(1,\ldots,k\) strictly exceed all counters labelled \(k+1,\ldots,r\).

If the current index belongs to the first group, incrementing its counter preserves this strict separation. Its updated rank count is at most \(k\), so the next index also belongs to that group. Repetition freezes every counter in the second group, contradicting their divergence.

This argument requires persistence of the **labelled separation**, not persistence of the inequality \(s_k-s_{k+1}>2D\). The original wording is correct, but explicitly distinguishing these would make the argument easier to audit.

Therefore the selected counter belongs to the lower group whenever the gap exceeds \(2D\). Its old value is at most \(s_{k+1}\); incrementing it cannot raise \(s_k\), while no order statistic can decrease. Hence the gap cannot increase. Combined with the general one-step increase bound, this proves (17).

**7. The finite-state conclusion follows from a proved uniform bound.**

Summing the bounded sorted gaps bounds the entire counter range. The normalized counters therefore take values in a finite set. The next normalized state is uniquely determined by the present state, since both incrementing and rank comparison are unchanged by adding a common constant.

A repeated state yields a periodic tail by determinism. This establishes eventual periodicity without relying on simulation.
