## Mathematical target and exact theorem

Let p be prime, $p\equiv1\pmod{840}$. Set

$$x=x_{19}=\frac{p+19}{4},\qquad B=px.$$

Then $5\mid x$ and $p>19$. The fixed A=19 gate asks whether positive integers $x<y<z$ satisfy $4/p=1/x+1/y+1/z$. Its complete Type I/II criterion is

$$(19y-B)(19z-B)=B^2,$$

equivalently a divisor $d\mid B^2$ with $d\equiv-B\pmod{19}$. Both factors must be positive: each reciprocal is strictly less than their sum $19/B$. Also $B$ is a unit modulo 19, so the complementary divisor automatically has the same residue. Normalize $d\le B$ and construct

$$y=\frac{B+d}{19},\qquad z=\frac{B+B^2/d}{19}.$$

Because $p>19$, $y>B/19>x$. Equality $y=z$ would force $d=B$, incompatible with $B\equiv-B\pmod{19}$ for a unit. Thus the construction meets the strict Epoch/Erdős 242 contract.

For $B=\prod q^{e_q}$, write $d=\prod q^{e_q+t_q}$, $-e_q\le t_q\le e_q$. The gate opens exactly when

$$\prod q^{t_q}\equiv-1\pmod{19}.$$

With primitive root 2, the target is logarithm 9 in $C_{18}$. Aggregate exponents in inverse-paired classes into $w=(w_1,\ldots,w_9)$:

## Why the finite certificate proves completeness

Let

$$R(w)=\left\{\sum_{j=1}^{9}jt_j\pmod{18}:\ |t_j|\le w_j\right\}.$$

Prime factors with the same inverse-paired log class combine to exactly the interval $[-w_j,w_j]$: sums of integer intervals have no holes, and replacing a log by its negative does not change a symmetric interval. Therefore the prime-factor signed box is exactly R(w), not merely the subgroup generated by the factors.

1. A class j has order $18/\gcd(j,18)$. At exponent $\lfloor\operatorname{ord}(j)/2\rfloor$, its symmetric interval reaches that entire cyclic subgroup. Further exponent increases add no residues. These are exactly the nine caps above, so $R(w)=R(\bar w)$ for arbitrary valuations.
2. The downset D of the twelve displayed rows, restricted to $w_2\ge1$, has exactly 230 profiles. Its base is $b=(0,1,0,0,0,0,0,0,0)$.
3. For every $w\in D$, the certificate computes R(w) and checks $9\notin R(w)$.
4. For each of those 230 profiles and each of the nine coordinates, let v be the capped increment. All **2,070** checks establish either $v\in D$ or $9\in R(w)+\{-j,0,j\}$. Before saturation this sum is exactly R(v). At saturation v=w and is already in D.
5. Starting at b, reach any capped profile by coordinate increments. If it exits D, its first exit has target 9 by step 4, and all subsequent additions retain that target by monotonicity. If it ends inside D, step 3 excludes the target. Hence no unlisted obstruction is possible. The prime-factor reduction gives the stated theorem.

This is a finite exhaustive **group certificate plus a general written reduction**, not an extrapolation from finitely many primes.

## Bounded-complexity corollary

Box 5 is precisely the pure quadratic-residue case: every factor of B has even log. If an obstructed B has any quadratic nonresidue, it cannot lie in box 5 and must lie below one of the other eleven boxes. Every entry in those eleven rows is strictly below its saturation cap. Thus no large raw valuation is hidden by clipping, and

$$\sum_{q\mid B,\ q\not\equiv1\ (19)}v_q(B)\le7.$$

Moreover no factor may belong to classes 7, 11, 14, 15 or 18 modulo 19 in a mixed obstruction. Neutral factors $q\equiv1\pmod{19}$ remain unrestricted. This does **not** bound B, prove scarcity of primes, or force a later gate. In particular, arbitrarily large neutral factors cannot be discarded in a root proof.

A useful sufficient condition follows directly: $v_5(x)\ge4$ fills the even subgroup of order nine. If x then has any nonresidue factor, Type II opens. Conversely a pure-QR x also makes p QR because $p\equiv4x\pmod{19}$, leaving the full gate closed. This conditional is known cyclic-group reasoning, not a new root solution.

### A conceptual proof using the stabilizer, not the table

The packet bound also has an independent written proof using classical [Kneser's addition theorem](https://arxiv.org/abs/1303.3539): for finite nonempty sets A and C in an abelian group, with $H=\operatorname{Stab}(A+C)$, one has $|A+C|\ge|A+H|+|C+H|-|H|$. We use only its aperiodic case and iterate it; this is an application of an established theorem, not a novelty claim.

Suppose R is a mixed signed box in $C_{18}$ containing the forced summand $S_2=\{0,\pm2\}$ and some odd-log summand $S_r=\{0,\pm r\}$, but missing 9. Its stabilizer H is trivial:

- If H has even order, it contains 9, contradicting $0\in R$ and $9\notin R$.
- If H has order 9, then R contains the even subgroup and its odd translate, hence all of $C_{18}$.
- The only remaining nontrivial possibility is order 3, $H=\{0,6,12\}$. But $S_2+H$ already fills the even subgroup, and $S_r+S_2+H$ fills both parity cosets, again impossible.

The odd summand cannot have r=9 (target already present), nor r=7 up to sign (7+2=9). For r=1,3,5 up to sign, the merged initial summand $S_2+S_r$ has respectively 7,9,9 elements. If M is the total nonzero-log valuation, the remaining M−2 unit summands each have three elements. A period of any partial sum would persist in the final R, so every partial sum is aperiodic. Iterating Kneser gives

$$|R|\ge7+2(M-2)=2M+3.$$

Since the missing target imposes $|R|\le17$, $M\le7$. This proof explains why the finite-packet phenomenon occurs, independently of enumerating the twelve rows. Python and unit tests also check trivial stabilizers and this cardinality inequality on every mixed closed capped profile. **This Kneser-based proof is not formalized in the Lean source.**

The same argument in $C_{2\ell}$ for an odd prime $\ell\ge5$ gives $M\le\ell-2$ whenever a target-avoiding mixed box has a primitive even-log summand. There the only possible nontrivial periods have order 2 or $\ell$, and both are excluded as above. Normalize the primitive even log to 2 by an odd unit automorphism. A merged even/odd initial pair has at least seven elements unless it already hits $\ell$: a duplicate among its nine sums requires $2\Delta t+r\Delta s=0$ with $|\Delta t|,|\Delta s|\le2$; non-target odd r can reduce the pair only to seven. Thus $2M+3\le2\ell-1$. In particular this recovers the three-unit bound for A=11 and gives a **nine-unit necessary bound** for mixed A=23 obstructions, since $3\mid x_{23}$ and 3 has order 11 modulo 23. This does not classify all A=23 packets or force A=23 to open.

The real next obligation is **a cross-shift argument**, not another unsupported small-A universal bound. For $p=840t+1$,

$$x_{11}=3(70t+1),\qquad x_{19}=5(42t+1),\qquad x_{19}-x_{11}=2.$$

These odd numbers are coprime. The root program must explain whether the exact splitting/finite-packet constraints can persist across further shifts, including unrestricted neutral factors. A candidate implication must survive the existing hard exclusions (2521, 131041, 4037881, 10051441, 171348241), with proposal-time exact replay, before spending another agent round on prose proof.
