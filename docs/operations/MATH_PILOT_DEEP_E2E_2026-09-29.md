## Protocol

1. Seal an exact universal auxiliary claim: for every prime `p≡1 (mod 840)`, a
   decomposition exists with first denominator `(p+A)/4` for some
   `A=3,7,...,47`. State separately that failure of this bound does **not**
   refute the unrestricted Erdős–Straus equation.
2. Let the model attempt it; obtain argument-critic and counterexample-hunter
   reviews in separate contexts. Convert a retained gap into one finite task,
   not a fabricated universal conclusion.
3. Preserve primary-source excerpts and metadata leads as a partial dossier.
   The source gate permits only `RESEARCH_ONLY`; the task verifier checks exact
   interval and quantifiers. A source gate `HOLD` remains immutable.
4. Run the TypeScript exact survey, then separately execute the pinned Python
   standard-library interval and exclusion tools. A `PASS` requires identical
   prime count, first failure, rescue bound, per-prime manifest and all per-A
   rows. Solver and two AI peer reviews run only after that check.
5. Retain the event-digest chain, provider usage and a finite-vs-unbounded
   conclusion. A polynomial family, if proposed, receives an exact
   coefficient-identity check but still no novelty or root-theorem promotion.
