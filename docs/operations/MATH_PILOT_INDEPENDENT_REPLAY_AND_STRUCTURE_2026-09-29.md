# Math Pilot: independent executable replay and structural frontier

Date: 2026-09-29. Scope: local Erdős–Straus research procedure only. No paid API,
deployment, theorem acceptance, or claim of novelty.

## Gate 1: arithmetic must be replayed by a separate executable

For new V3 residual surveys, the worker runs two fixed Python 3 standard-library
programs after the TypeScript `COMPUTED` event and before the solver or either
AI review role. The interval program independently re-enumerates every eligible
prime and first admissible A, reconstructs each first witness, and produces the
same per-prime SHA-256 manifest format as the product. If there is a first
failure, the second program independently trial-tests primality, factors each
`px`, enumerates all factor pairs for every `A=3,7,...,maxA`, and returns their
counts. The worker compares the full manifest, interval counts, first failure,
rescue A, and every per-A row. It retains script and output hashes, row counts,
comparison status, and report hash in an append-only `INDEPENDENT_REPLAY` event.
Only `PASS` permits solver dispatch; a mismatch stops the round. Historical V2
cycles remain readable but are not retroactively relabeled as tool-replayed.
The worker pins both reviewed script-body SHA-256 values and stops if either
file drifts before execution.

This is **implementation-independent arithmetic replay**, not formal proof,
independent model review, or a complete literature search. A SHA-256 match is
meaningful because the Python tool actually executes and builds the per-prime
records independently; a hash alone would not be evidence. It remains a local
trust boundary: a compromised worker or both implementations sharing a mistaken
mathematical specification could invalidate the result.

## Gate 2: a structural proposition, proved but not novel

Let `p≡1 (mod 840)` be prime, let `A≡3 (mod 4)` be positive with `A<p`, and set
`x=(p+A)/4`, `b=px`. Then `gcd(A,b)=1`. A solution with this fixed first
denominator exists if and only if there is a divisor `d|b²` with `d≤b` and
`d≡−b (mod A)`. Indeed, after removing `1/x`, the equation is
`1/y+1/z=A/b`. It is equivalent to `(Ay−b)(Az−b)=b²`. Both factors are
positive, and `d=Ay−b≤Az−b` when `y≤z`. Conversely, take such a `d` and put
`e=b²/d`. Since `gcd(A,b)=1`, `d≡−b (mod A)` implies
`e≡b²d⁻¹≡−b (mod A)`. Therefore `y=(b+d)/A` and `z=(b+e)/A`
are positive integers and satisfy the original equation.

For `A=3`, `p≡1 (mod 3)` and `x=(p+3)/4≡1 (mod 3)`, so `b≡1 (mod 3)`.
The divisor criterion becomes: the `A=3` gate succeeds **if and only if**
`x` has a prime factor `q≡2 (mod 3)`. In the forward direction, an admissible
`d≡2 (mod 3)` must contain such a prime; `p≡1 (mod 3)` so it belongs to `x`.
In the reverse direction, set `d=q≤x≤b`. This gives the explicit exact witness
`y=(b+q)/3`, `z=(b+b²/q)/3`.

Thus every residual prime left after the first gate has
`(p+3)/4` in the multiplicative semigroup generated by primes congruent to
`1 (mod 3)`. This is a **general structural classification of the first
residual layer**, not a proof that the layer is empty and not a new result.
The already-curated prior-art catalog records the same A=3 criterion.

For illustration, the progression `p≡8401 (mod 9240)` forces `11 | (p+3)/4`,
and `11≡2 (mod 3)`, so every prime in that progression passes `A=3`. The
progression is coprime to its modulus, so Dirichlet's theorem supplies
infinitely many such primes. This is a familiar modular-family consequence,
not a new resolution of the hard residual classes.

There is a useful but only one-way next-layer obstruction. For `A=7`, we have
`p≡1 (mod 7)`, `x=(p+7)/4≡2 (mod 7)` and `b≡2 (mod 7)`. If every prime
factor of `x` has residue in the quadratic-residue subgroup `{1,2,4}` modulo
7, then every divisor of `b²` stays in that subgroup, whereas the required
residue `−b≡5 (mod 7)` is outside it. Thus the `A=7` gate fails. The replayed
prime `171348241` illustrates the intersection: `x₃=42837061` is prime and
`1 (mod 3)`, while `x₇=42837062=2·21418531` has factor residues `2` and
`1 (mod 7)`. This explains the first two failed gates without enumerating
every factor pair, but it does **not** classify all A=7 failures, much less
force a solution at a later A. The subgroup argument is a direct corollary
of the known divisor criterion and is not claimed as novel.

## Prior-art comparison and open next claim

- [Bradford, *Elementary Patterns from the Erdős–Straus Conjecture*, Integers
  25 (2025)](https://math.colgate.edu/~integers/z54/z54.pdf), Propositions 1–4,
  already proves the Type I/II divisor-congruence equivalence for fixed `x`.
- [Bloom and Elsholtz, *Egyptian fractions* (2022)](https://www.math.tugraz.at/~elsholtz/WWW/papers/bloom-elsholtz-naw5-2022-23-4-237.pdf)
  discusses the established modular-cover approach and the residual square
  classes modulo 840.
- The local prior-art catalog also cites the A=3 prime-factor criterion; that
  source is a preprint and does not confer novelty on this derivation.

The next genuine research target is **not** another larger finite interval.
It is a statement that controls the intersection of the surviving layers,
for example an unbounded theorem forcing an admissible divisor for some A
after `A=3` fails. Such a theorem must include exact quantifiers and a proof
independently checked line by line; its scope must then be compared against
primary literature. At present no such new theorem has passed those gates.

## Gate 3: machine-checkable parametric claims, without theorem inflation

The local solver contract now accepts up to two polynomial families with
nonnegative integer coefficients. The worker checks the coefficient identity
`4xyz=n(xy+xz+yz)` exactly with `BigInt`, positivity for every integer `t≥0`,
and that `n(t)=n₀+mt` is a primitive progression contained in `1 (mod 840)`.
If `4x(t)−n(t)` is a positive constant, that offset is retained explicitly so
the reviewer can compare it against the root case's permitted `A` range.
The result is retained in a `PARAMETRIC_CHECKED` event and recalculated when
the digest chain is read. Both reviewer contexts receive the family and the
deterministic result but must assess the remaining quantifier and prior-art
gaps. This checker certifies one polynomial identity, **not** a proof of the
root problem, the primality of each term, originality, or a formal proof in a
proof assistant. The UI labels that boundary explicitly.

A regression certificate uses `n(t)=73921+85680t`, `q(t)=272+315t`,
`u(t)=n(t)q(t)`, `x(t)=68q(t)`, `y(t)=68(u(t)+1)/63`, and `z(t)=u(t)y(t)`.
All denominator coefficients are nonnegative integers. Here
`n(t)=272q(t)−63`, `u(t)≡−1 (mod 63)` coefficient-wise, and exact arithmetic
proves the identity for every `t≥0`. Because `gcd(73921,85680)=1`, Dirichlet's
theorem implies infinitely many prime values in this progression. At `t=1999`,
`n=171348241`, the previously replayed `A≤59` failure, while this construction
has `A=4x−n=63` and gives a checked positive decomposition. This is a useful
**bridge from one replayed finite failure to an infinite rescue progression**.
The rescue `A=63` is deliberately outside the auxiliary `A≤59` claim; it does
not rehabilitate that false bound.
It does not assert that every prime in this progression fails `A≤59`; most may
pass earlier gates. In particular, the progression adds a factor `17` to the
modulus (`85680=840·102`); its residue is `5 (mod 17)`, a nonsquare. It cannot
be extrapolated to all primes `1 (mod 840)`. The modular construction and
divisor method require full literature comparison before any novelty claim;
none is made here. Bloom–Elsholtz's [survey of Egyptian
fractions](https://www.math.tugraz.at/~elsholtz/WWW/papers/bloom-elsholtz-naw5-2022-23-4-237.pdf)
describes the established residue-class approach and its square-class
obstruction; this comparison is contextual, not an exhaustive novelty audit.

A second, closer-to-test lift starts at the independent `A≤47` failure
`p=10051441`. Put `p(t)=10051441+1239000t`, `k(t)=6701+826t`, and
`m(t)=114+14t`. Then `k(t)+25=59m(t)`,
`x(t)=375k(t)=(p(t)+59)/4`, `y(t)=375p(t)m(t)`, and
`z(t)=15p(t)k(t)m(t)`. All coefficients are nonnegative integers. Directly,
`1/y+1/z=(k+25)/(375pkm)=59/(px)=4/p−1/x`.
The coefficient checker returns `PROGRESSION_IDENTITY`, fixed offset `A=59`,
digest `26047ecb97cbbc92706e9c506bbc061018b522a2b0a77aa897611dcc4466fe9c`.
At `t=0` it reproduces the exact witness retained by the finite survey.
`gcd(10051441,1239000)=1` and the step is divisible by 840, so this also
contains infinitely many prime values. It is a concrete unbounded *rescue
subfamily*, not a proof that later terms fail `A≤47`, and not a novelty claim.

Acceptance matrix for a new research cycle:

1. A proposed gap must quote the retained review, state exact domain and
   quantifier, and pass distinct-context/source gates before solver work.
2. A finite exclusion needs a complete interval manifest and a PASS from the
   separately executed Python replay; mismatches stop before solver review.
3. An unbounded family needs a valid polynomial certificate. Invalid or absent
   certificates cannot be promoted from persuasive prose or AI agreement.
4. A theorem claim needs a logically complete proof for its stated domain,
   adversarial checking of omitted cases, and primary-source comparison.
   Until then it remains a partial result or hypothesis, never “solved”.

The new browser E2E acceptance gate remains separate from unit/integration
checks. An existing terminal cycle must not be retroactively rewritten; run a
fresh OPEN case and observe the events in the UI before declaring that gate
passed.
