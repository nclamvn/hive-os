# TIP-010 — Dashboard and Navigation

Status: `DRAFT`

## Task

Implement the locked dashboard experience from real mission and system state.

## Acceptance Criteria

- New Mission composer is the primary action.
- Active mission rows show type, phase, derived progress, next gate, and real update time.
- Right rail shows current mission, decision-required activities, and measured resources.
- Bottom metrics display only when backed by authoritative queries; otherwise show honest empty states.
- UI is calm, dense enough for experts, understandable to first-time users, and faithful to the locked mock.
