## Requirements / testable acceptance

- R1: Certify occupancy of the BAD OPEN arc ||phase+q/d||<1/N for
  complete d-point grids using exact rationals. Generate every critical phase
  ±1/N−q/d modulo1, all boundary points, and all intervening open intervals
  including wraparound. The independent consumer derives required boundaries,
  adjacency, representative/mask arithmetic and maximum occupancy; no missing,
  overlapping, duplicate, unreachable or fabricated phase cell is accepted.
  Check ceil(2d/N) bound, equality being GOOD. Explain why the predicate is
  constant on each open cell. This is written mathematical justification plus
  exact arithmetic replay, not Lean/formal proof or a mere rational sampling.
- R2: Separately type congruence-class applicability. If g>1 divides M and
  every residue, exclude only that entire nonprimitive integer class. For
  omit-one shift require g|M, all fixed residues divisible by g, and the
  exception coprime to g (or explicitly certify its actual nontrivial orbit).
  For few exceptions require14 moving speeds, prime d,2<=e and
  e*ceil(2d/15)<d; all fixed coordinates divisible, all exceptions units mod d.
  Lower cases/primitivity/distinctness/positive speeds must remain explicit.
  Missing common shift, composite nonunit exceptions, weak inequality and
  missing lower premise cannot become unconditional witnesses/theorem results.
  Bound lengths, denominators, cells, work/time/input/output. Never enumerate
  huge old fibers or alter their coverage counts.
- R3: Fresh independently implemented Python replay runs only pinned checked
  source bytes and bounded JSON input, shell=false/isolated interpreter, before
  a new finite LRC solver call. Add optional supplemental properness evidence
  to the existing host envelope; old absent evidence remains byte/digest-readable.
  Pure admission rejects coherent rehashed scope/summary/certificate/source or
  global-claim faults. Supply identical compact conditional facts to solver,
  critic and adversary, no raw proof code. Provider/model output cannot inject
  this evidence. Replay mismatch/incomplete certificate blocks model dispatch.
  Existing fixed-grid/NO_GRID semantics and PARTIAL conclusion must persist.
- R4: Retain a new compact source-versioned report. Actual examples include the
  four TIP048 fixed divisible-by7 classes, independently derived from immutable
  retained source scope, and clearly labeled conditional shift controls for
  N15,d3,e2 and N15,d5,e2/3/4. Never claim these controls are author terminals.
  New bilingual proof-dossier section displays phase completeness, mechanisms,
  outstanding premises and provenance; source23 global obligations remain OPEN.
  Missing/corrupt report fails closed without numbers or success claims. No
  subprocess/old validator/network/model on proof-view GET; preserve selectors.
- R5: Real fresh replay, boundary and completeness attacks, finite controls,
  historical envelope regressions and actual mocked-model prompt/gate tests.
  Main separately reviews mathematical scope and live browser responsiveness.
  Completion reports include requirement counts, tests, issues/deviations and
  explicit NOT_RUN global gates. No process receipts counted as signed proof.
