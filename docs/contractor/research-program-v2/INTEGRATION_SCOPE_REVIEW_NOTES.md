## Decisions proposed for seal

1. **Private diagnostics are orthogonal to mathematical admission.** A diagnostic v1 manifest distinguishes input capture, actual dispatch, transport closure and admission. The same parser accepting bytes during offline replay creates no retained attempt, job success, ledger or obligation closure. Counterfactual parser results never replace original versions/outcomes.
2. **Capture raw bytes before decoding and exact host input before dispatch.** Prepared JSON contains the exact original `stdin`/`schemaText`; compare their UTF-8 byte counts/digests to actual stdin and output-schema writes. No regeneration/truncation of model input. Stream hooks capture raw stdout only on the scoped new lane; login status, stderr, environment and Codex history are excluded. Child failure still closes a bounded partial capture before a safe failure receipt.
3. **Use the existing transport, not another executor.** Optional scoped observation on the existing shell-free Codex helper preserves default legacy errors/returns/caps. A new pure admission registry has no env/DB/provider imports and only pinned host code, never code loaded from captured data. Old062/063/064 semantics, invocation and persisted encodings remain untouched.
4. **Authorization is session authority, not metadata.** Existing session authentication and current exact membership/resource capabilities mint a process-local grant. Original actor plus `research.read`/`jobs.manage` and explicit local permission is required for replay/purge; dispatch also requires `research.request`. An OWNER/ADMIN who is not the original actor still refuses. A copied WorkspaceContext or serialized grant does not authenticate. Recheck current authority before each sensitive operation.
5. **Quota is a cross-process storage bound.** Reserve one slot and 1,146,880 worst-case bytes under an exclusive filesystem lock before model dispatch. The calculation is 49,152 prepared bytes + 1,048,576 stdout bytes + 16,384 manifest bytes + 32,768 optional actual host finite-evidence bytes. Main explicitly accepted the extra bounded host record allowance, with the same 100-capture/128MiB global quota and unchanged model/checker limits. Reserve the critic slot before the host finite check, retain actual evidence even when critic never dispatches, then capture exact critic input before model. Failure to reserve prevents checker/new model dispatch; checker failure records its truthful status, not invented evidence. Control/summary data is additionally bounded and charged within the global quota, not outside it. Count <=100 includes incomplete/reserved captures. Use O_EXCL/no-follow regular-file and ancestor identity checks, complete writes, file/directory sync. An interrupted lock/reservation is not silently taken over or released by trusting PID/time heuristics; stop dispatch and expose maintenance-required state. Unknown unsafe files refuse, not follow/delete.
6. **Expiry is not deletion.** Replay expires after 24h. Bytes remain private and charged until explicitly authorized maintenance selects <=10 opaque IDs, <=16MiB and a cooperative <=5s operation. No root/glob deletion, daemon or GET cleanup. Record truthful partial cleanup, keep remaining reservations, show overdue retention, and allow quota exhaustion to block dispatch. Never claim protection against the same OS account/admin or encryption at rest.
7. **Failure is retained without another call.** Capture storage failure after dispatch aborts only the owned child, reports partial/unknown execution with actual known IDs, and prevents another role/retention/retry. A SIGKILL does not hard-preempt pending JS/DB/filesystem work. No detached racing task may later mutate a job after a reported timeout.
8. **Mathematical versioning is additive.** Adopt Core's proposed `LRC_METHOD_UNIT`, contract-v4/ledger-v7, host `lrcMethodUnitEvidence`/`lrcMethodUnitInput`, model `lrcMethodUnitFeedback`, and ledger audit summary. Fixed baseline/unit/source/predicate and actual external case/run binding are mandatory. New/malformed markers refuse before generic OPEN fallbacks; ES cycle refusal expands additively, never unlocks LRC there.

## Transport, replay and authenticity limitations

The manifest records exact actual source pins and parser/renderer versions. Replay accepts only the installed pinned pure registry; unavailable/drifted version refuses. It must not import an old capture as executable source or weaken refusal to make it replay successfully. The safe public schema is finite: codes, allowlisted issue paths, bound IDs, counts/digests, completeness and availability—not provider strings, offending values or file paths. Unknown errors map to a safe boundary, not an invented cause.

Observed thread/usage is independently parsed from unique coherent lifecycle/accounting events and labelled TRANSPORT_OBSERVED_UNACCEPTED until actual admission. Missing/ambiguous fields remain UNAVAILABLE. A complete code-0 transport is not evidence that no tool ever ran; observed tool activity refuses, but capture cannot undo it or attest hidden host behavior.

Coherent mutation tests compare captured content against independent trusted host binding/source/digest anchors, not merely a hash the attacker can replace in the same manifest. No local hashing arrangement authenticates an adversary controlling all code/storage/anchors. This ceiling stays explicit.
