# VISION — HIVE OS v0.1

## Product identity

**HIVE OS** is a provenance-preserving operating system for Human-AI research, engineering, and decision-making.

It is not a chatbot with tools. It is a stateful mission system in which claims, evidence, decisions, transformations, verification, and releases have explicit semantics.

## User promise

The user provides:

1. an objective;
2. files, links, or data;
3. answers to strategic questions;
4. approvals at material checkpoints.

HIVE OS returns:

- a mission contract;
- an execution plan;
- traceable claims and evidence;
- verified artifacts;
- explicit limitations and unresolved branches;
- a governed result package.

## Experience principles

1. **Natural at entry, rigorous underneath.** Mission intake feels as simple as writing a question.
2. **Truth before completeness.** Honest-null and disputed states are visible and respected.
3. **Progress is semantic, not decorative.** Progress is derived from closed obligations, never an arbitrary percentage.
4. **Human attention is scarce.** Interrupt only for material decisions.
5. **Deep detail is one click away.** The default view is calm; provenance and audit depth remain inspectable.
6. **No AI theater.** Avoid glowing agents, animated neural graphics, and vanity activity feeds.
7. **Cross-model responsibility.** Every agent run records role, provider, model, input artifact, output artifact, and verifier status.

## Primary personas

- Principal investigator / research owner.
- Engineering or product owner.
- Analyst / economist.
- Manufacturing or quality leader.
- Independent reviewer / auditor.
- Operator / administrator.

## v0.1 mission types

- Research
- Analysis
- Build
- Evaluate

Mission type changes assurance defaults and available skill plans, but all types share the same truth and governance kernel.
