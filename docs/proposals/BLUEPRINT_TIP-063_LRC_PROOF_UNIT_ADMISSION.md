preserve062 case, contract, evidence and ledger immutably. Use the existing
research/verification architecture, not a second ungoverned execution system.
One target only: the source-conditional terminal/cascade/common-level bridge

The packet must distinguish:

1. Definition and exact statement, domain, quantifiers, units, permutations,
   signs, primitive/gcd and labelled/unlabelled conventions.
2. Mathematical proof, with each step connected to a named premise or lemma.
3. Computational evidence: finite check, coverage certificate, historical

   bridge or absence of every omitted branch.
4. Reproduction debts, local failures and which claims remain source-conditional.
