## Actual streamed protocol / child boundary

Exact075D INPUT/OUTPUT magic and tag+u64LE-length framing. CONTROL and each COMMIT/
DESCRIPTOR are canonical bounded JSON; events use length-prefixed inert bytes,
TABLEs arrive in ascending numeric size, then DATA, SEGMENT_END, STREAM_END and
mandatory EOF. No path references, code, pickle, base64, complete-prefix rawbytes
or complete-prefix descriptor list is sent to a child. Metadata scan retains the
bounded filename inventory and only the current descriptor/tail/cursor.

Parent input is a lazy closeable generator over one descriptor and one bounded
blob chunk at a time. Child full replay feeds every logical event independently,
checks exact cursors, and uses genuine producer/checker row iterators; it does
not call their materializing tables()/dataset() APIs. Every TABLE reader must
verify length, ordering and SHA at its actual EOF before the next frame is opened;
DATA has the same EOF obligation. Supplied rows never become a semantic oracle.

The only retained raw event body is ONE outgoing GEN segment, bounded by
segmentBytes. GEN stops BEFORE requesting a next event when fewer than46 bytes
remain (4-byte framing plus maximum42-byte event), preventing an applied but
unpublished cut. Parent reconstructs its count and logical byte delta before
commit. Worker output writes require exact integer full-write count, not bool,
None or silently ignored partial return. Actual pipe/file partial writes are
handled by the parent without accepting incomplete output.

Popen receives `sys.executable -I -S -B -c` plus the SAME verified OWN host bytes
with a fixed literal __file__, not a subsequently reopened host path. Child loads
only SAME SHA-checked OWN producer OR checker bytes. Exact six environment values
are false, shell=false, close_fds=true, no inherited file/path authority in the
stream. Source size is bounded131072 per file; before/after pins are checked.
Worker's conservatively charged fixed-source reads are six source-bound units,
not falsely reported as precisely measured physical I/O.

stdin writes, stdout and stderr reads are concurrent and nonblocking. stdout goes
to an O_EXCL durable spool, not a resident response buffer. stderr retains at most
its declared bounded prefix in an O_EXCL file; any stderr disallows acceptance.
Read request sizes are bounded BEFORE effect by remaining read/stream/stderr
allowance. At exhaustion a single bounded EOF probe can detect overflow and
refuse; nonempty over-cap probes never yield an accepted result. Positive payload
with nonzero exit, timeout, malformed output, stderr or post-load pin drift is
never adopted.

Timeout cleanup kills, waits at most one2s cleanup interval, then STOP if unreaped.
Selector, every pipe, lazy input generator/its held blob fd, stderr and spool are
all attempted closed even if another close/fsync fails; cleanup failure prevents
positive acceptance. This is not a process-tree/hostile privileged-OS sandbox.
