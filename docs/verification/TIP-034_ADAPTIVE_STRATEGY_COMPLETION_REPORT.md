## Precisely retained epistemic boundaries

`TYPED_PREDICATE_REFUTED` carries the exact registered claim ID plus evidence digest, or the exact probe plan plus plan/report digests and `REGISTERED_PREDICATE_ONLY`. Its originating prose hypothesis is not certified equivalent or false. Generic counterexample arithmetic replay is only a finite checked fact unless separately bound to the actual predicate. Attempt/review memory is derived from real ATTEMPTED/REVIEWED/refutation events, not coarse ROUND_CLOSED or the older proof-obligation label. REVIEWED_ARGUMENT is still an AI-reviewed argument, never a theorem or novelty certificate.

Publication ACTIVE means no withdrawal observed in that captured authoritative record, not correctness of the mathematics. Unavailable/stale/historical background is not promoted into current accepted premises; known withdrawn sources are quarantined publication-wide, including aliases. New-policy frontier admission rejects credentialed/nonstandard-port/non-HTTP(S) source URLs and known-withdrawn primary/discovery identities. The fixed fetcher remains server-owned; no model URL is fetched.

New policy uses a retained root contract whose digest must match the trusted root policy for known-scope selection replay. Historical source freshness is checked at the retained `admittedAt` boundary, not today's clock. V1 history is neither upgraded nor regraded; no synthetic adaptive panel or new packet is created for an old trace.
