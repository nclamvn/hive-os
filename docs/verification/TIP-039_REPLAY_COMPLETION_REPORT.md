## 2. Independent implementation and mathematical challenge

Python does not import primary outcomes, factors, images, projections, minima,

parent h, factors parent T, exact q valuation and parent QNR character; then
checks q prime 1 mod4, c=3q<p, integral T and gcd(T,c)=1. Registered Jacobi
is computed as the product of the two prime Legendre symbols, not an Euler
exponent modulo c. Independent trial factorization and square-root divisor
enumeration build every ordered positive coprime pair uv|T. Full S consists
of u/v modulo c. Numeric lex minima use u<=v separately for the joint target
and each local target. A local projected pair is never promoted to a strict
three-denominator witness.

For misses, H is searched only within S, justified by 1 in S. Exact quotient
orders are reduced from phi(c)=2(q-1) by factoring phi and testing powers in H;
no scan of all c units or unbounded linear order loop occurs. Python integer
and checker BigInt modular products remain exact. Four involutions are solved
by CRT and their intersection with H is retained independently.

Builder B challenged the generic deduction before adopting consistency guards.
If an atom's signed interval saturates its cyclic subgroup, translating that
interval by the atom leaves the total image unchanged, placing the atom in H.

quotient lower bound gives |S/H|>=1+2V; absence of the target gives
|S/H|<=n-1, hence 2V<=n-2. The missing (-1)H is a nonidentity order-two element,
so n is even. This does not imply H odd, n=2 mod4, or any prime-shift character
classification. This analytic challenge is not formal proof or novelty review.
