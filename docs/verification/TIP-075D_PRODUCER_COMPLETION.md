## Genuine row streams / call-time generation fence

iter_table_rows(size:int) and iter_dataset_rows() are ordinary methods returning
closeable RowIterator objects. They capture b.events on API CALL, precharge and
sort BEFORE returning, not lazily at first next. Current support/UNION iterate a
bounded sorted pointer list of existing immutable bytes; finalized compact table
iterates fixed-width row slices. Neither path calls tables(), dataset() or _raw().
Every next checks Engine health, exact fence and deadline before and after its
bounded row; a changed fence or failure permanently poisons Engine and closes
the iterator. Table-size range is checked before string conversion, including
huge values. Empty tables genuinely reach EOF with no row.

Iterator workspace =4096+256*N+128+width for set-backed rows; compact finalized
table workspace =4096+128+width. Reservation occurs before sort/conversion and
remains charged across concurrent iterators until close/exhaustion/fault. The
iterator has explicit idempotent close and destructor fallback. Main approved
this finally-equivalent wrapper because an unstarted Python generator.close()
does NOT run its finally; explicit close releases even before first next. No
cache/disk-merge architecture was introduced. Caller-owned rows/output retention
is not falsely claimed contained by the Engine budget.

Cursor incrementally SHA-hashes every sorted table/UNION row with bounded digest
state, not joined copies, and preserves exact old hash semantics. FINAL_END UNION
hash also uses row iteration. SUPPORT_END still makes the bounded finalized raw
table required for extension indexing. Sorting and hashing remain charged work,
not O(1), with after-sort/after-hash deadline polls. No unordered-set checksum or
hash-only mathematical equality shortcut is used.

Tiny compatibility tables()/dataset() remain real bytes APIs and explicitly
precharge pointer/join/output workspace4096+256*N+width*N; tables additionally
reserves8192+sum(raw output sizes). Their iterators close even if copy precharge
fails. Streaming consumers need not use these materializing compatibility APIs.
Cursor workspace16384 plus each live row iterator remains accounted. Existing
constructor/frame/canonicalization/set reservations and aggregate retained-key,
logical-byte counters are preserved. Limits concern conservative algorithmic
working allocations, NOT hard Python RSS or OS containment.

An event or snapshot may tentatively advance internal state before a failure;
the Engine is poisoned and cannot publish accepted events/cursors/rows/data after
that failure. Host must discard uncommitted output and reconstruct only the full
committed prefix. No rollback, refund or saved-frontier authority is provided.
