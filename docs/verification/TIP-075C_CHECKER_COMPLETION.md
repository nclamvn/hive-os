## Implemented independent semantics

Verifier derives strict masks directly from scalar modular distances and SETs,
checks equal nonzero cardinality, derives size/private quota/root combinations,
and reconstructs selected/available/private/covered independently at every node.
It checks the first applicable monotone/capacity/union/gain prune and deterministic
pivot/options. Its explicit DFS frames remove cumulative earlier options and
push the pending first child before a branch-event cursor returns.

Every exact event is computed independently, compared byte-for-byte BEFORE its
effects, then applies complete leaf/support/canonical-UNION effects. It checks
global root schedule, logical footer node/byte counts, SUPPORT_END before extras,
every combinations-with-replacement tuple (including one empty tuple), SIZE_END
consumption and FINAL_END exact sorted DISTINCT UNION. No expected source rows,
tau bound, producer truth flag or vote is consulted.

Current partial minimal tables and finalized tables are exposed together and
bound in cursor hashes. Finalized tables persist across sizes. finish requires
TERMINAL plus exact table-key/content and dataset equality. Verdict is ONLY
TINY_G_VERIFIED_CTB_OPEN, semanticVerified true, wholeGrant0, wholeAttempts4 and
derived tiny row count. Prefix cannot finish; supplied cursors are not adopted.

Any feed/parser/type/budget/finish/snapshot refusal permanently poisons the
verifier. Allocation/overflow/recursion faults also poison and become bounded
refusals. Catching a bad final event, wrong finish or malformed input cannot
permit later acceptance. Tests check these paths separately from ordinary
negative mutations, which each start from a fresh otherwise-valid baseline.
