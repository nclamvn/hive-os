# Governed Authoring

Mission-scoped documents are mutable pointers to immutable, content-hashed
revisions. Each revision retains ordered sections, human-readable citations,
computational artifact references and a deterministic quality report.

Current editorial checks block raw tool tokens, unresolved citations, empty or
missing required sections and unsourced authority claims. Unsupported certainty
and quantitative claims prompt review. Narrow local EN/VI patterns recognize
user-attributed input quantities and negated guarantees; these are heuristics,
not fact checking or source validation. Dashes, formulaic prose and dense
paragraphs are optional style advice, excluded from content scores/status.
AI-assistance disclosure is not itself a finding. This is not an AI detector.

List, editor and export recompute current rules using the actual document type;
export renders the latest saved revision, not unsaved edits. Historical v1
reports stay immutable and history scores are labeled as recorded at save.
Issue category is derived from code; unknown codes conservatively mean content.

LaTeX, CAS results, notebooks, datasets and code are retained as hashed
artifacts. This module does not execute arbitrary code, browse the web, call a
model provider, approve a Mission or turn generated text into governed truth.
Those actions require separate adapters and authority.
