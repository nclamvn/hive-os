# Governed Authoring

Mission-scoped documents are mutable pointers to immutable, content-hashed
revisions. Each revision retains ordered sections, human-readable citations,
computational artifact references and a deterministic quality report.

Current editorial checks block raw tool tokens, unresolved citations, empty or
missing required sections and unsourced authority claims. Unsupported certainty
and quantitative claims prompt review. Narrow local EN/VI patterns recognize
user-attributed input quantities and negated guarantees; these are heuristics,
not fact checking or source validation. Dashes, formulaic prose and dense
paragraphs are optional style advice, excluded from content scores/status.
AI-assistance disclosure is not itself a finding. This is not an AI detector.

List, editor and export recompute current rules using the actual document type;
export renders the latest saved revision, not unsaved edits. Historical v1
reports stay immutable and history scores are labeled as recorded at save.
Issue category is derived from code; unknown codes conservatively mean content.

LaTeX, CAS results, notebooks, datasets and code are retained as hashed
artifacts. This module does not execute arbitrary code, browse the web, call a
model provider, approve a Mission or turn generated text into governed truth.
Those actions require separate adapters and authority.

The optional manual update panel copies the current draft/context for a human
Codex handoff and previews a bounded JSON update pack. It validates document,
base revision and exact old section bodies, then applies all replacements to the
unsaved draft. It does not change headings, citations, artifacts or imports.
Changing draft content, request or packet after preview requires a fresh preview.
An ordinary, separately previewed appendix retains declared inputs, unknowns and
checks; explicit Save persists it with the concise change summary. No new model
call, database table or global export gate is introduced.

Cost checks interpret canonical JSON numbers as decimal rationals and round
half up to two currency decimals per included line, then sum. Inputs are bounded
at 1e9 and totals at 1e12. Unit conversion covers area and length only; cost
quantities additionally support item counts. Unknown included costs require a
null claimed total, never a guessed zero. Explicitly bundled exclusions retain
their reasons. NOT_MET threshold results remain retainable negative evidence;
invalid units and mismatched cost claims block this panel's apply only.
The checker does not compare every number in prose, verify field data or quotes,
or approve commercial/technical acceptance. Normal editorial and export checks
still apply to the new text and evidence appendix, including citation markers.

Numeric-source review now separates locally declared input/synthetic quantities
from empirical assertions and bounded cost calculations. Two prose expression
forms (quantity × unit price, or a sum of at most eight amounts) reuse the exact
update checker; wrong/ambiguous calculations receive a calculation warning, not
a request to add a citation. Generated appendix details are treated as declared
inputs/calculations only after strict parsing and transcript replay. All free
text, citations and tool traces remain inspected. TEST, APPENDIX or MATCH labels
alone do not grant immunity. This does not authenticate inputs, bind an appendix
to an authorized runtime, validate sources, or understand every paraphrase.
